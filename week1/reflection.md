Installing MySQL on my own laptop really helped me understand why databases are way better than simple file-based systems. When using regular files, data gets duplicated easily, it's hard for multiple people to access it at the same time, and things can easily get messed up or corrupted. Having a DBMS like MySQL centralizes everything in one place, keeps the data accurate, and lets us query or update records safely without breaking the whole setup.

Once this database starts getting used for real student and course records, the DBA responsibility that becomes super important right away is Security and Access Control Management. Before anyone actually uses the system, the DBA needs to create different user accounts and set strict permissions. For example, students should only be allowed to view their own grades, while registrars need permission to add or update courses. Setting up proper access rules right from the start protects sensitive student data from unauthorized changes and keeps the database secure.
